## Key Features

- **Neo-Brutalist Aesthetic:** High-contrast color blocks, heavy borders, brutalist offset drop-shadows, and tactile physical hover states.
- **Custom Canvas Pixel Cursor:** Interactive pixelated mouse pointer with a dynamic ghosting trail and color-inversion blending.
- **Kinetic GSAP Animations:** Waterfall hero entrance, parallax scroll scrub, and interactive hover-scale 5x5 abstract grid.
- **Interactive Portrait with Camera Shutter:** Clean, natural-color professional photo card featuring an interactive camera shutter flash and lens snap on hover.
- **AI Clone Chatbot (`Harshith_AI`):** An embedded assistant powered by Groq (`openai/gpt-oss-120b`) with strict context grounding to answer questions about Harshith's experience, hackathon wins, and technical projects.
- **Full-Screen Resume Modal:** Embedded PDF viewer with live inline preview, download button, body-scroll locking, and spring entrance animations.
- **Smart Contact Actions:** 1-click launch of Gmail Web Compose with pre-filled recipient plus simultaneous clipboard copy with live visual feedback.
- **Zero Placeholder Grid:** Curated project dossiers highlighting engineering metrics, awards, and technical specifications.

## Local Development Setup

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm` / `yarn`

### 2. Clone the Repository
```bash
git clone https://github.com/Harshith404/portfolio-website.git
cd portfolio-website
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```
> Obtain a free API key at [console.groq.com](https://console.groq.com/).

### 5. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 6. Production Build
```bash
npm run build
npm run preview
```
